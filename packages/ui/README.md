작고 재사용 가능한 기본 요소

컴포넌트 설명
Checkbox, Radio 체크/선택 요소

🔹 컴포지션 UI (Molecules)
조합된 중간 컴포넌트

컴포넌트 설명
FormField label + input + 에러 메시지 일체형
Modal, Dialog 팝업창 (기본/확인/에러용)
Tooltip 마우스 hover 시 정보 표시
Toast 간단한 알림창
Pagination 페이지네이션 구성
Table 헤더/바디/정렬 가능한 테이블
Tabs 탭 UI 컴포넌트
Accordion 펼침형 FAQ 등

🔹 Layout / Navigation
컴포넌트 설명
Header, Footer 상단/하단 공통 구조
Sidebar, Drawer 왼쪽 슬라이드 메뉴 등
Breadcrumbs 경로 표시 (홈 > 마이페이지 > 주문)
Card, Panel 틀을 잡아주는 구조용 컨테이너

🔹 기타 유틸 컴포넌트
컴포넌트 설명
LoadingSpinner 로딩 표시용 컴포넌트
EmptyState 데이터 없음 화면 ("검색 결과가 없습니다")
ErrorBoundary 에러 처리용
Skeleton 로딩 중 뼈대 UI

👍 2 Toast, Tag, Checkbox, LoadingSpinner
